# Cannabis anatomy — literature starter

Started: 2026-09-12.

This separate folder contains descriptive botanical research and an inventory of evidence gaps. It does not contain cultivation guidance, defoliation automation, a robot task, or a calibrated simulation.

## Current evidence

The starting references are taxonomic flora descriptions and one original leaf-identification study. Search-index excerpts were reviewed; the paper's complete text and figures have not been inspected. No partner specimens, photographs, measurements, or mechanical data have been supplied for this study.

No strawberry measurements have been transferred. No geometry, physics parameters, or validated model has been produced.

## Research discipline

Keep four labels separate: **reported in a source**, **observed in a specimen**, **inferred**, and **unknown**. Record specimen identity and source context before treating an observation as representative. A plausible drawing is not a measurement, and a numerical model running stably would not establish biological accuracy.

An appropriate next botanical milestone is an annotated reference atlas distinguishing a whole leaf, its leaflets, the petiole, and their attachment to the stem, with each image's provenance and uncertainty visible. That atlas has not yet been assembled.
