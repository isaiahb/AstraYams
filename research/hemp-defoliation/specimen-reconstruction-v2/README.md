# Specimen reconstruction v2

Preserves v1. Adds six coarse visible blade contours and a source-photo plane in the matching projection. The plane is only a comparison aid, not geometry, collision, segmentation or a second camera observation. Source crop, credit and uncertain organ identity remain in specimen.json.

This is a partial 2D trace embedded in 3D; not a complete plant or physically validated simulation. Ten patches are not ten complete leaves. No new biological growth rules or cultivation parameters. See the visible acceptance gates in index.html.
